according to object oriented programming languages:  [ C++/java/C#]

void add(int a, int b)
{
	a+b
}

void add(char a,char b)
{
	a+b
}

void add(char *a,char *b)
{
	a+b
}

	This is called as "function overloading"
advantage is that "caller will have to remember only one name i.e. add "

Polymorphism is an ability of an object to take multiple forms:

static polymorphism  [ happens at compile time ]
		function overloading and operator overloading

dynamic polymorphism  [ happens at runtime ]
		function overriding
