

why do we define "public" class? Is it compulsory?
	No it's not compulsory to make a class public. However if you are a developer and are going to distribute your class to client/s, then in order to make it accessible to all the clients , you must make your class "public".


// developer   - at a different location
public class Student
{
	// data and functions
}


// client - at a different location
public class Demo
{
	main()
	{
		accessed "Student" class
	}
}

	{
		S.o.p("Hello");
	}
}

how will you save your file?
ans:  you must save it by "A.java"

	javac A.java
		A.class

	java A

if we save above code by some other name e.g. "Demo.java"

	javac Demo.java
		compiler error :- class "A" is public and it must be inside "A.java"
